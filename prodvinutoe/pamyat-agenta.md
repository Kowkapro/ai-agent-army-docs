# Память агента

По умолчанию агент помнит текущий разговор. Но есть и долгосрочная память — факты которые сохраняются между сессиями.

## Как работает память

OpenClaw хранит важные факты в файле `MEMORY.md` в папке workspace. Агент читает его при каждом старте.

Ты можешь сам добавлять туда всё что важно:

```bash
nano ~/.openclaw/workspace/MEMORY.md
```

Например:

```markdown
# MEMORY.md

## Проекты
- Основной проект: парсер новостей на Python, лежит в /home/user/newsparser
- Сервер: 192.168.1.100, root доступ по SSH

## Предпочтения
- Всегда использовать Python 3.11+
- Логи хранить в /var/log/myapp/
- Бэкапы в /backup/ с датой в имени

## Важные детали
- API ключ от сервиса X хранится в /etc/secrets/api.key
- Nginx конфиг: /etc/nginx/sites-available/myapp
```

## Автоматическое запоминание

Агент сам записывает важные факты если ты скажешь:

```
Запомни что основной сервер у меня 192.168.1.100
```

```
Запомни мои предпочтения по коду: всегда добавлять type hints в Python
```

## Поиск в памяти

```
Что ты знаешь про мой проект?
```

```
Напомни какие у меня серверы
```
