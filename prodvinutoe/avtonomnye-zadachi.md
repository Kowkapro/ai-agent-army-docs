# Автономные задачи по расписанию

Агент может работать без тебя — по расписанию, сам.

## Cron в OpenClaw

Ты задаёшь задачу, время, и агент выполняет её сам. Без твоего участия.

Написать агенту:

```
Каждый день в 9:00 утра присылай мне сводку: использование диска, памяти и аптайм сервера
```

```
Каждый понедельник в 10:00 проверяй есть ли обновления безопасности и присылай список
```

```
Каждые 5 минут проверяй доступность сайта example.com, если упал — сразу пиши мне
```

## Примеры реальных автономных задач

**Мониторинг сервера:**
Агент каждый час проверяет CPU и RAM. Если что-то превышает порог — пишет в Telegram.

**Публикация контента:**
Агент каждое утро берёт тему из очереди, пишет пост, публикует в канал.

**Дайджест новостей:**
Агент каждый вечер парсит нужные источники, составляет краткую сводку, присылает тебе.

**Бэкапы:**
Агент каждую ночь делает резервную копию важных папок, проверяет что бэкап успешен.
