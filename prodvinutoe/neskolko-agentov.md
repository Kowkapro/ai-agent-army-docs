# Несколько агентов

OpenClaw поддерживает несколько агентов в одной системе — каждый со своей специализацией.

## Зачем несколько агентов

Один агент универсален. Но когда задач становится больше, удобнее иметь специализированных:

- **Основной агент** — общение, задачи, управление
- **Кодер** — только разработка, знает весь стек проекта
- **Контент-менеджер** — пишет посты, управляет каналом
- **Мониторинг** — следит за серверами, присылает алерты

## Как создать второго агента

В OpenClaw каждый агент — это отдельный workspace:

```bash
openclaw workspace create coder
```

Настрой ему свой `SOUL.md`:

```bash
nano ~/.openclaw/workspaces/coder/SOUL.md
```

Пример для агента-кодера:

```markdown
Ты — специализированный агент для разработки.
Стек: Python, Node.js, PostgreSQL, Redis.
При написании кода всегда добавляешь обработку ошибок и логирование.
Знаешь проект: парсер новостей в /home/user/newsparser.
```

## Общая память

Все агенты могут читать общую память. Что один агент узнал — другой тоже будет знать при следующем старте.
