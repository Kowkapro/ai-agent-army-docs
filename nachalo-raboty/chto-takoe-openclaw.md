# Что такое OpenClaw

OpenClaw — это платформа для запуска персональных AI-агентов на своём сервере.

Ты разворачиваешь его на VPS за $5-15/мес, подключаешь к Telegram, и у тебя есть агент который:

- Отвечает на сообщения 24/7
- Помнит контекст между разговорами
- Выполняет задачи: пишет код, ищет информацию, управляет файлами
- Запускает задачи по расписанию пока ты не в сети
- Работает с несколькими агентами в одной системе

## Для кого это

**Если ты разработчик** — агент который пишет код, делает ревью, отвечает на вопросы по проекту. Не надо открывать браузер, всё в Telegram.

**Если ты предприниматель** — агент который мониторит нужные темы, готовит дайджесты, управляет задачами, публикует контент.

**Если просто хочешь автоматизировать рутину** — OpenClaw делает то что ты делал бы сам, только быстрее и без твоего участия.

## Чем это отличается от ChatGPT или Claude

| | ChatGPT/Claude | OpenClaw |
|---|---|---|
| Где работает | Серверы OpenAI/Anthropic | Твой сервер |
| Память | Забывает после сессии | Помнит всё |
| Автоматизация | Только по запросу | По расписанию, автономно |
| Интеграции | Ограничены | Telegram, Discord, WhatsApp и др. |
| Контроль | Нет | Полный |
| Цена | Подписка | Только стоимость VPS |

## Что внутри

OpenClaw — это gateway который соединяет:
- **Модель** (Claude, GPT, Gemini — на выбор)
- **Канал** (Telegram, WhatsApp, Discord, Signal)
- **Инструменты** (файлы, терминал, браузер, API)
- **Память** (контекст между сессиями)
- **Cron** (задачи по расписанию)

Всё это работает на одном процессе, на одном VPS, за несколько минут установки.
