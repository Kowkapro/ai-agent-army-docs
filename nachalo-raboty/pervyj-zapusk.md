# Первый запуск и настройка

Агент установлен и отвечает в Telegram. Теперь настроим его под себя.

## Как устроен агент

OpenClaw запускает **workspace** — рабочее пространство агента. Там хранятся:

- `SOUL.md` — личность и стиль агента (кто он, как говорит)
- `USER.md` — информация о тебе (имя, timezone, предпочтения)
- `AGENTS.md` — инструкции для агента (что делать, какие задачи)
- `memory/` — долгосрочная память

## Первые команды

Напиши боту в Telegram:

```
Привет, как тебя зовут?
```

Агент представится. По умолчанию он использует имя из конфига.

```
/status
```

Покажет статус системы — модель, канал, версию.

```
Что ты умеешь?
```

Агент расскажет о своих возможностях.

## Настроить личность агента

Файл `SOUL.md` в папке workspace определяет как агент себя ведёт. Открой его:

```bash
nano ~/.openclaw/workspace/SOUL.md
```

Напиши кто этот агент — его имя, стиль общения, в чём специализируется. Агент будет следовать этому описанию в каждом разговоре.

## Рассказать агенту о себе

Файл `USER.md`:

```bash
nano ~/.openclaw/workspace/USER.md
```

Пример:

```markdown
# USER.md

- Имя: Женя
- Timezone: GMT+3
- Основные задачи: разработка, автоматизация
- Стек: Python, Node.js, Linux
```

Агент будет учитывать это в ответах.
