# Как давать задачи агенту

Агент понимает обычный текст. Не нужны специальные команды или синтаксис — пиши как человеку.

## Простые задачи

```
Найди документацию по Qdrant и объясни как работает фильтрация
```

```
Напиши скрипт на Python который парсит RSS-ленту и сохраняет в JSON
```

```
Проверь есть ли место на диске и покажи топ-5 самых тяжёлых папок
```

## Задачи с контекстом

Агент помнит что было раньше в разговоре. Можно продолжать:

```
Ты: Напиши функцию для отправки сообщения в Telegram
Агент: [напишет функцию]

Ты: Теперь добавь обработку ошибок
Агент: [доработает ту же функцию]

Ты: Покажи как её использовать
Агент: [даст пример]
```

## Задачи с файлами

```
Прочитай файл /home/user/config.json и объясни что там настроено
```

```
Создай файл deploy.sh со скриптом деплоя для Node.js приложения
```

## Как формулировать задачу правильно

**Плохо:** `сделай что-нибудь с базой данных`

**Хорошо:** `подключись к SQLite базе /data/app.db, выведи список таблиц и покажи первые 10 записей из таблицы users`

Чем конкретнее — тем точнее результат.

## Длинные задачи

Агент справляется с многошаговыми задачами:

```
Мне нужно настроить мониторинг сервера:
1. Установи htop и ncdu
2. Создай скрипт который каждый час проверяет использование CPU и RAM
3. Если CPU > 80% — пришли мне уведомление в Telegram
4. Запусти это как cron задачу
```

Агент выполнит всё по порядку, спросит если что-то непонятно.
