# Как общаться с агентом

## Агент — не поисковик

Не нужно формулировать запросы как в Google. Пиши как человеку:

**Не так:** `python скрипт парсинг json файл сохранение`

**А так:** `Напиши мне скрипт на Python который читает файл data.json и сохраняет только записи где поле "status" равно "active" в новый файл result.json`

## Агент помнит контекст

В рамках разговора агент помнит всё что говорилось раньше. Можно ссылаться на предыдущие сообщения:

```
Ты: Создай функцию для подключения к базе данных
Агент: [создал]

Ты: Добавь в неё логирование
Ты: Теперь напиши тесты для неё
Ты: Покажи всё вместе
```

## Если агент ошибся

Просто скажи об этом:

```
Это неправильно, у меня Ubuntu а не Debian, поправь команды
```

```
Не то что нужно. Мне нужен не список а конкретное число
```

```
Ты не учёл что у меня нет sudo доступа, сделай без sudo
```

## Уточнения

Если задача неоднозначная — агент спросит. Это нормально. Лучше уточнить чем угадывать.

## Прерывание задачи

Если агент делает что-то не то — просто напиши:

```
Стоп, я имел в виду другое
```

```
Забудь про это, давай сначала
```

## Длинные ответы

Если ответ слишком длинный:

```
Коротко, только суть
```

```
Дай только финальный код без объяснений
```
